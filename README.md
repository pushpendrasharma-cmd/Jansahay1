# JanSahay (जनसहाय) - Rajasthan Government Schemes Portal

> **Sarkari Yojna, Saral Bhasha Mein (सरकारी योजना, सरल भाषा में)**  
> Understand Rajasthan government schemes in plain, jargon-free language. Check basic eligibility for education, healthcare, housing, farming, and social security.

---

## 🌟 Key Features

- **Multi-lingual Support**: Seamless bilingual toggle between English and Hindi (हिन्दी).
- **Interactive Eligibility Checker**: Wizard to discover schemes you qualify for based on age, category, income, and occupation.
- **Rich Scheme Directory**: Comprehensive catalog covering healthcare, agriculture, women & child development, education, youth employment, and pensions.
- **Application Checklist & Document Guide**: Clear breakdown of required documents (Jan Aadhaar, Aadhaar, Income certificate, etc.) and step-by-step application procedures.
- **Smart Filtering & Search**: Instant filtering by department, category, and eligibility parameters.
- **Responsive & Accessible**: Modern, accessible UI tailored for both mobile and desktop screens.

---

## 🚀 Getting Started

### Local Setup
Since JanSahay is built with vanilla HTML, CSS, and modern JavaScript, no build step or node installation is strictly required:

1. Clone the repository:
   ```bash
   git clone https://github.com/pushpendrasharma-cmd/Jansahay1.git
   cd Jansahay1
   ```

2. Open with any local web server (e.g. VS Code Live Server, Python HTTP server):
   ```bash
   python -m http.server 8080
   ```

3. Open `http://localhost:8080` in your browser.
